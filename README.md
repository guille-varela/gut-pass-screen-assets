# gut-pass-screen-assets

Image assets for GUT's password screen (`pass-screen` skill in the GUT AI Library).

Copy everything in `assets/` into the `assets/` folder of the build you are protecting:

```bash
gh repo clone guille-varela/gut-pass-screen-assets -- --depth 1
cp gut-pass-screen-assets/assets/* <build>/assets/
```
